# Security Policy

## Reporting a Vulnerability
Please do not report security vulnerabilities through public GitHub issues or pull requests.

1. Use [GitHub's private vulnerability reporting](https://github.com/wecamo-io/gpupcb/security/advisories/new) if enabled.
2. Alternatively, contact the repository maintainers privately.
3. Include a description of the vulnerability.
4. Provide steps to reproduce the issue, if possible.
5. Include any potential impact and if possible, suggested remediation.
6. Include the HyperLynx file that causes the issue, if it is related to the file parsing process.
